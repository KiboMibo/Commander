# Чек-лист: Python (Django, FastAPI, Flask)

Проходи от точек входа: вьюхи, роутеры, обработчики задач Celery, CLI-команды, потребители очередей.

## Выполнение кода и инъекции

- **Команды.** `subprocess` с `shell=True` и f-строкой — RCE. `os.system`, `os.popen`, `commands.*` — то же самое без вариантов. Безопасная форма: список аргументов без `shell`.
- **Код.** `eval`, `exec`, `compile` от данных запроса. Реже, но встречается в «конструкторах правил» и калькуляторах формул.
- **Десериализация.** `pickle.loads`, `yaml.load` без `SafeLoader`, `marshal`, `shelve`, `dill` на внешних данных — прямое выполнение кода. `yaml.safe_load` обязателен; `pickle` для данных из сети недопустим в принципе, даже «подписанный».
- **SQL.** `cursor.execute(f"...")`, `.raw()`, `.extra()`, `text()` в SQLAlchemy со склейкой. ORM защищает, пока не вышли в raw. Отдельно: `order_by` и имена колонок из запроса нельзя параметризовать — нужен allow-list.
- **Шаблоны.** SSTI: `render_template_string` с пользовательской строкой, Jinja2 `Template(user_input)`. Через `{{ ''.__class__.__mro__ }}` это выходит в RCE.
- **Пути.** `open(os.path.join(base, request.args['f']))` — traversal. Нужен `os.path.realpath` плюс проверка префикса, либо `pathlib` с `.resolve()` и `is_relative_to`.

## Веб-фреймворки

**Django**

- `DEBUG = True` в продакшен-конфиге — раскрытие настроек и трассировок. Блокер.
- `ALLOWED_HOSTS = ['*']` — host header poisoning, отравление ссылок сброса пароля.
- `SECRET_KEY` в репозитории; ключ, попавший в коммит, подделывает сессии и токены — ротация обязательна.
- `csrf_exempt` на вьюхах, меняющих состояние.
- `QuerySet` без фильтра по владельцу: `Order.objects.get(pk=pk)` вместо `Order.objects.get(pk=pk, user=request.user)`.
- `mark_safe`, `|safe`, `format_html` с пользовательскими данными.
- `SECURE_SSL_REDIRECT`, `SESSION_COOKIE_SECURE`, `CSRF_COOKIE_SECURE`, `SECURE_HSTS_SECONDS` в продакшене.
- Права: `permission_classes` в DRF заданы явно, а не полагаются на дефолт `AllowAny`; `serializer` не отдаёт лишние поля (`fields = '__all__'` — типовая утечка).

**FastAPI**

- Зависимость аутентификации навешена на роутер, а не забыта на отдельных эндпоинтах. Проверь `include_router(..., dependencies=[...])` и точечные исключения.
- Pydantic-модель ответа задана (`response_model`), иначе в ответ уходит всё, что вернула функция, включая хеш пароля.
- `/docs` и `/openapi.json` открыты в продакшене — оцени, приемлемо ли раскрытие схемы.
- Валидация: типы описаны моделями, а не `dict`; `Optional[str]` там, где на деле обязательное поле, — дыра в проверках.

**Flask**

- `app.run(debug=True)` — интерактивная консоль Werkzeug, это RCE. Блокер.
- `SECRET_KEY` захардкожен или пустой — подделка сессионных cookie (они подписаны, но не зашифрованы; не клади в сессию ничего секретного).
- Отсутствие CSRF-защиты на формах (нет `flask-wtf` или ручной проверки).

## Секреты и конфигурация

- Ключи и строки подключения в `settings.py`, `config.py`, `docker-compose.yml`, ноутбуках `.ipynb` (там же остаются в выводах ячеек), фикстурах тестов.
- `.env` не в `.gitignore`.
- Значения по умолчанию вида `SECRET_KEY = os.getenv('SECRET_KEY', 'dev-secret')` — в продакшене при незаданной переменной приложение молча поднимется с известным ключом. Лучше падать.

## Сеть и внешние вызовы

- `requests`/`httpx` с `verify=False` — отключённая проверка сертификата.
- SSRF: URL из запроса в `requests.get`. Нужен allow-list, запрет приватных диапазонов и `169.254.169.254`, контроль редиректов (`allow_redirects=False` с ручной проверкой).
- XXE: `xml.etree`, `lxml`, `xmlrpc` на внешнем XML. Используй `defusedxml`.
- ZIP/tar: распаковка архива от пользователя без проверки путей внутри (zip slip) и суммарного размера (zip bomb).

## Криптография и токены

- `random` вместо `secrets` для токенов, кодов подтверждения, паролей. `random` предсказуем.
- `hashlib.md5`/`sha1` для паролей. Нужны `argon2`, `bcrypt`, `scrypt` или `pbkdf2_hmac` с достаточным числом итераций.
- Сравнение через `==` для подписей и токенов вместо `hmac.compare_digest`.
- Самописное шифрование вместо `cryptography`; режим ECB; статический IV.

## Утечки

- Логирование `request.POST`, `request.headers`, объектов пользователя целиком.
- Возврат `str(e)` клиенту — часто содержит SQL, пути и параметры подключения.
- `print` отладочной информации, оставшийся в продакшен-коде.
- Разные ответы или заметно разное время при существующем и несуществующем аккаунте.

## Прочее

- `assert` для проверок безопасности — вырезается при запуске с `-O`.
- Изменяемые значения по умолчанию в аргументах, разделяющие состояние между запросами.
- Celery/RQ: задачи, принимающие произвольный callable по имени; брокер без аутентификации.
- Загрузка файлов: проверка по расширению вместо содержимого, сохранение под именем из запроса, отсутствие лимита размера.
